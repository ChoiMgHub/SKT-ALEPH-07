# 과제 7 안내 68개 기준 재검수

기준 자료: SKT-ALEPH-07-1.png부터 SKT-ALEPH-07-6-3.png까지 8장. 검수일: 2026-10-26(서울).

## 판정

인증·자료 분리·내보내기·설명·상세 요청 증거와 하루 모의 체험을 구현했다. 실제 5일 사용과 실제 기록에 근거한 규칙 변경·전후 해석은 미충족이다. 하루 모의 체험의 다섯 구간을 실제 다섯 날짜라고 기록하지 않는다. 심사자의 모든 기준 통과나 단축 인정·면제를 보장하지 않는다. 추가 공개 화면은 소스를 받은 뒤 Worker 재배포가 필요하다.

## 증거의 출처

- 사용자: 공개 배포, 일반/시크릿 계정 분리·백업 이전, 원격 49개 PASS 터미널 출력. 사용자 PC의 원격 상세 JSON은 받지 않았다.
- AI: 격리된 workerd/D1 임시 계정으로 별도 실행한 49개 점검과 익명화한 요청·응답·저장값 비교 결과·불변성 비교. [상세 증거](auth-evidence.md), [전체 JSON](../public/verification.json). 비밀번호·쿠키·pepper는 가렸고 임시 계정은 2/2 정리했다. 공개본은 계정명·ID도 익명화하고 저장 해시를 제외했다. 해시가 포함된 원본은 비공개이며 공개 승인을 받지 않았다.
- 실제 화면: 사용자가 가입·로그인한 AI 시험 계정에서 1일분 5분 기록·새로고침·내보내기 확인. 사용자의 실제 5일 실험과 구분한다.
- 하루 체험: 로그인·계정 API 없이 오늘 5구간을 조작하는 순서형 모의 체험. 모든 조작 시각은 현재 시각이며 과거·미래 날짜를 생성하지 않는다.

## 비공개 증거와 공개 승인

원본 임시 계정의 저장 해시·식별자·상세 인증 기록을 포함한 GitHub 반영은 자동 승인 검토에서 거절됐다. 공개본은 이를 익명화하고 해시 원문을 제거했다. 해시가 포함된 원본은 사용자 확인용 비공개 파일로 분리했으며 GitHub에 올리지 않았다. C103·C104의 원본 값 제출은 이 비공개 증거를 검토한 뒤 제출 대상에 맞게 처리해야 한다.
