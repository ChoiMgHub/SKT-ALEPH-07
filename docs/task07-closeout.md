## ④ 어떤 시험을 했고 무엇이 확인됐는가

### 사용자가 실행한 시험

사용자는 Windows PowerShell에서 전체 자동 테스트 30개 통과, 원격 기록 스키마 적용, 공개 배포 성공 출력을 제공했다. 별도의 원격 권한 점검은 49개 PASS, 임시 계정 정리 2/2로 종료됐다. 여기에는 정상 사용자 허용과 다른 계정의 조회·수정·삭제 거부, 피해 자료 불변성, 세션 무효화 등이 포함된다.

상세 요청·응답·저장 해시 보고서는 사용자 PC의 `.private/auth-verification-remote.json`에 있다. 이 파일은 아직 제출 문서에 첨부하지 않았으며, 터미널 요약만으로 상세 증거까지 첨부됐다고 쓰지 않는다. 비밀번호·쿠키·pepper는 공개하지 않는다.

### AI가 직접 화면에서 한 시험

사용자가 별도 시험 계정의 가입·로그인을 마친 뒤 AI가 공개 앱을 조작했다. 계획 1개와 할 일 1개를 만들고 계획 수정·할 일 완료를 확인했다. 음수 입력은 차단됐고, 오늘 기록 뒤 추가 저장 버튼과 질문 수정이 막혔다. 새로고침 뒤 로그인과 자료가 유지됐으며 JSON 내보내기에는 계획·수정 이력·할 일·완료 이력·오늘 기록이 포함됐다. 내보내기에서 비밀번호·pepper·쿠키·토큰·세션 관련 필드는 발견되지 않았다.

측정 구간은 서울 시각 2026-10-26 15:29:44.613부터 15:35:04.795까지 약 5분 20초였고, 가장 가까운 정수 분인 5분을 기록했다. 이는 AI의 브라우저 점검 구간이며 전체 개발 시간이나 사용자의 복습 시간이 아니다. 진행 상태는 1/5일이다. 원래 다이어리의 실행 시간에는 별도 실행 기록을 넣지 않았으므로 0분이며, 05의 측정값 5분과 구분한다.

AI가 예상 시간 입력 중 기존 값에 숫자를 붙여 5,120분으로 잘못 저장한 건은 5분으로 수정했다. 수정 전 값은 이력에 남았다. 이 건은 앱 오류로 분류하지 않았다.

### 오늘 끝낸 가상 5일 기능 시험

다음 명령으로 격리된 메모리 DB와 jsdom 화면에서 가상 날짜를 전달하는 기존 시험을 다시 실행했다.

```powershell
node --test test/study.test.js test/study-ui.test.js
```

결과는 **6개 통과, 실패 0개, 건너뜀 0개**다. 아래 숫자는 계산 검증용 합성값이며 실제 활동 측정값이 아니다. 날짜는 시험 함수에만 전달하며 공개 API에 날짜를 임의 지정하는 기능을 추가하지 않았다.

| 모의 차수 | 가상 서울 날짜 | 합성값 | 적용 규칙 |
|---|---|---:|---|
| 1일차 | 2026-10-26 | 20분 | 변경 전 |
| 2일차 | 2026-10-27 | 30분 | 변경 전 |
| 규칙 변경 | 2일차 뒤·3일차 앞 | — | 두 원본 기록의 ID·사본·변경 이유 보존 |
| 3일차 | 2026-10-28 | 30분 | 변경 후 |
| 4일차 | 2026-10-29 | 40분 | 변경 후 |
| 5일차 | 2026-10-30 | 50분 | 변경 후 |

수기로 계산하면 합계는 `20+30+30+40+50=170분`, 전체 평균은 `170÷5=34분`, 변경 전 평균은 `(20+30)÷2=25분`, 변경 후 평균은 `(30+40+50)÷3=40분`, 평균 차이는 `40−25=+15분`이다. 자동 시험은 같은 값이 서버 집계와 화면에 나오는지 확인했다. 합성 자료이므로 실제 규칙이 시간을 15분 늘렸다는 효과를 주장하지 않는다.

시험은 서울 날짜 경계, 음수·소수·빈칸·소급 날짜 거부, 같은 날 중복, 첫 기록 뒤 질문 고정, 규칙 변경 시점과 근거 보존, 여섯 번째 날짜 거부, 누락일 처리, 동시 재시도, 내보내기·계정 분리·삭제 후 격리도 확인했다.

## ⑤ AI와 내 판단 — 제출용 3줄

AI에게 맡긴 일: 인증과 자료 분리·백업·5일 기록 기능의 설계와 구현, 자동 시험과 권한 점검 도구 작성, 별도 계정의 화면 시험, 검수와 문서 정리를 맡겼다.

내가 판단하고 수행한 일: 과제 6을 이어 별도 과제 7 저장소·Worker·DB로 구분하고, 내 PC에서 설치·명령 실행·Cloudflare 인증·DB 적용·배포를 진행했다. 두 계정의 자료 분리와 백업 가져오기를 확인했으며, 오늘은 하루 집중 시험 결과까지 정리해 작업을 마감하기로 했다.

AI 제안을 따르지 않은 일: 실제 날짜를 나누어 5일간 사용한 뒤 마무리하자는 일정 대신 오늘 정리해 달라고 요청했다. 따라서 이번 정리는 기능 검증 중심이며 실제 5일 사용 조건을 충족했다고 적지 않는다.

## ⑥ 남은 조건과 한계

- 실제 5일 사용, 실제 두 기록에 근거한 중간 규칙 변경, 실제 전후 결과 해석은 미충족이다. 모의 시험 6개 통과와 구분한다.
- 원격 권한 점검 상세 JSON은 미첨부다. 사용자 실행 요약과 실제 원본 보고서의 범위를 구분한다.
- PBKDF2 반복 횟수와 pepper 보관·복구, 간단한 요청 제한 등의 보안 한계는 [인증 구현 기록의 ⑥](auth.md#⑥-남은-문제와-보호-범위)에 남겼다. 이번 문서 정리로 보안 한계가 해소되지는 않았다.
- 시험 통과는 확인한 입력·환경의 결과다. 모든 오류가 없거나 과제 전체 기준이 충족됐다는 보장은 아니다.
