03 · RECORD

실제로 한 일

계획값을 바꾸지 않고 시작·종료·실제 시간을 따로 남깁니다.

실제 시간은 시작·종료 시각으로 계산합니다. 저장한 기록은 계획의 예상 시간을 덮어쓰지 않습니다.

실행 기록

입력·표시는 현재 기기의 시간대를 따릅니다. 실제 시간 단위는 분이며, 초 단위 차이는 가장 가까운 분으로 반올림합니다.

아직 실행 기록이 없습니다.

완료 이력

할 일당 최초 완료 한 건을 보존합니다. 되돌리면 현재 완료 집계에서는 빠지지만 이력은 남습니다. 완료 이력은 실제 작업 시간을 뜻하지 않습니다.

04 · SEE

돌아보기

숫자를 누르면 어떤 기록에서 나온 값인지 볼 수 있습니다.

계획 수는 선택한 계획에 연결된 삭제하지 않은 할 일 수입니다. 예상 시간은 그 할 일들의 합계, 실제 시간은 그 할 일에 연결된 실행 기록의 합계입니다. 차이 = 실제 − 예상. 기록하지 않은 시간은 포함하지 않습니다.
